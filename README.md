# Escape from Music Sir

A lightweight third-person 3D school stealth adventure set around an LGS State Life Senior Branch-inspired campus in Lake City Meadows, Lahore.

## Website
[Play Escape from Music Sir](https://salarkhurram989.github.io/escape-from-music-sir/)

If the website does not open yet, enable GitHub Pages in the repository settings: **Settings → Pages → Deploy from a branch → main → /(root)**. It may take a few minutes to publish.

You can also open `index.html` directly in a browser.

## Current gameplay
- Explore a low-poly 3D school building and outdoor campus from a third-person camera.
- Collect three music notes.
- Avoid Music Sir's patrol.
- Reach the main gate to complete the escape.
- Keyboard controls: WASD or arrow keys.
- Touch controls are available on smaller screens.

## Project
The game is built with HTML, CSS, JavaScript and Three.js (loaded from a CDN). No build step is required; an internet connection is needed to load the 3D engine.

The campus is a game-inspired representation, not a verified architectural floor plan of the real school.
