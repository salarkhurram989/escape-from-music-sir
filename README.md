# Escape from Music Sir

A browser-based school stealth adventure set around an LGS State Life Senior Branch-inspired campus in Lake City Meadows, Lahore.

## Play
Open index.html in a browser, or enable GitHub Pages for the repository using the main branch and root folder.

## Current gameplay
- Explore the school building and outdoor campus.
- Collect three music notes.
- Avoid Music Sir's patrol.
- Reach the main gate to complete the escape.
- Keyboard controls: WASD or arrow keys.
- Touch controls are available on smaller screens.

## Project
The game is a standalone HTML, CSS and JavaScript project. No build tools or external libraries are required.

The campus is a game-inspired representation, not a verified architectural floor plan of the real school.
